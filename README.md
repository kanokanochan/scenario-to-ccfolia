# シナリオPDF → ココフォリア変換ツール

TRPGシナリオのPDF・テキストファイルを読み込み、文章を自動でブロックに分割 → ブラウザ上で結合・分割・並べ替え・置き換え・編集 → ココフォリアの「シナリオテキスト」に一括登録できるzipとして書き出す、ブラウザだけで動く非公式のファンメイドツールです。

**ツールを開く 👉 https://kanokanochan.github.io/scenario-to-ccfolia/**

**使い方ガイド（PDF・画面付き） 👉 https://kanokanochan.github.io/scenario-to-ccfolia/guide.pdf**

## 特徴

- インストール不要。リンクを開くだけ（Mac / Windows / iPad / スマホ）。
- PDF（文字が選択できるもの）とテキスト（.txt、UTF-8 / Shift-JIS 自動判定）に対応。Word製PDFで一部の文字が読めない問題も解消済み（MuPDF採用）。
- ファイルは約6MBあるため、初回は開くのに数秒かかります。
- ファイルの中身は**あなたのブラウザの中だけ**で処理され、外部サーバーには一切送信されません。
- 書き出したzipをココフォリアの部屋にドラッグ＆ドロップすると、シナリオテキスト一覧に一括登録されます（既存の部屋データには影響しません）。

## 注意

- 非公式のファンメイドツールです。ココフォリア公式とは関係ありません。
- 生成したデータは、ご自身が遊ぶセッションの準備目的でのみご利用ください。シナリオの再配布にあたる利用はしないでください。

## クレジット

- PDF解析に [MuPDF](https://mupdf.com/)（Artifex Software, AGPL-3.0）の WebAssembly 版を使用しています。ローカル版(PyMuPDF)と同じエンジンなので、Word製PDFなどでも文字が欠けません。
- このページ自体のソースはこのリポジトリの index.html です。
